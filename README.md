# Chatbot with Knowledge

This project is a Kotlin Spring Boot chatbot that answers questions about:
- securities trade lifecycle
- custody and clearing services
- clearing and settlements

The application currently uses a mocked provider so it can demonstrate the chat flow without making a real OpenAI or ChatGPT API call. The backend exposes a simple REST endpoint that accepts a question and returns a deterministic answer generated by the mock provider.

## Running locally

1. Ensure Java 17 is installed and available on your PATH.
2. Start the application:
   `./gradlew bootRun`
3. Open http://localhost:8080 in a browser.

## Backend endpoint

POST `/api/chat`

Request body:
```json
{
  "question": "What is custody and clearing?"
}
```

Response:
```json
{
  "answer": "Mock answer: 'What is custody and clearing?' -> This chatbot can explain custody and clearing services in the securities trade lifecycle."
}
```

If the question is blank, the service returns HTTP 400 with a JSON error payload such as:
```json
{
  "error": "Question must not be blank"
}
```

## Testing

Run the project's verification suite:
```bash
./gradlew check
```

## Mocked provider note

The current provider is intentionally mocked and does not call OpenAI or ChatGPT. It is implemented behind a provider interface so the implementation can later be swapped for a real client without changing the controller or service contract.

## Future integration point

To replace the mock provider with a real AI client, implement the `ChatProvider` interface in a new class and wire it as the Spring bean used by `ChatbotService`. The controller and front-end contract remain the same, so the UI will continue to work without changes.
